# XPRIZE evidence pack

Keep originals containing customer names, phone numbers, payment details, or bank details in a private folder outside Git. Use redacted copies for screenshots/video.

- [ ] Cloud Run deployment URL and service configuration screenshot
- [ ] Vertex AI / Gemini usage evidence

- [ ] Public landing page and consent notice screenshot
- [ ] Baseline P&L: revenue R0, marketing spend R0, operating expenses recorded

- [ ] Agent trace: Radar decision, demo quote, explicit approval, payment-link status

- [ ] Honest testimonial or feedback, including permission to quote it

- [ ] Public three-minute video: Radar -> owner approval -> voice note/demo -> quote -> payment -> dashboard

- [ ] P&L and required expense disclosure
- [ ] GitHub repository access granted to both required reviewers
- [ ] All screenshots and sample logs redact personal information
